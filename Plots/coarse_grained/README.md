# Coarse-Grained Valuation Experiments

This directory contains experiments for group-level data valuation using OpenDataVal.

## Structure

- **`tuning/`** - Hyperparameter tuning experiments and logs
- **`evaluation/`** - Evaluation results and metrics

## Running Experiments

### Tuning Phase

Place tuning scripts in `tuning/` and results in `tuning/results/`.

### Evaluation Phase

Place evaluation scripts in `evaluation/` and results in `evaluation/results/`.

## Configuration

Use YAML configuration files in `../configs/` to specify experiment parameters.
