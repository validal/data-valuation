# Skin Lesion Domain Adaptation Dataset

Domain adaptation benchmark for melanoma/skin lesion classification across different imaging domains.

## Dataset Overview

This dataset contains skin lesion images preprocessed as feature vectors for domain adaptation experiments.

**Task**: Binary/multi-class skin lesion classification with domain shift
- **Source Domain**: Labeled skin lesion images from the web
- **Target Domain**: Expert annotated images from HAM10000
- **Challenge**: Adapt classifier trained on source to perform well on target domain using data valuation
