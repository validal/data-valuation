# DataEvaluator Train/Eval Phase Report

This report is generated by `python -m opendataval.dataval.method_report`.

## What "train" and "eval" mean here

- **Train phase** = the evaluator's `train_data_values()` implementation, executed inside `DataEvaluator.train()`. 
- **Eval phase** = the evaluator's `evaluate_data_values()` implementation, executed inside the cached `DataEvaluator.data_values` property.
- The framework measures elapsed seconds (and CPU/GPU memory snapshots) around these calls and stores them in `memory_report` / `memory_report_eval`.

## AME

- **Module:** `dataval/ame/ame.py`
- **Method:** Implementation of Average Marginal Effect Data Valuation.
- **Train (`train_data_values`)**: Computes and stores intermediate statistics needed to value each training point.
- **Eval (`evaluate_data_values`)**: Returns the final per-point data values from stored statistics.

## BaggingEvaluator

- **Module:** `dataval/ame/ame.py`
- **Method:** Bagging Data Evaluator, samples data points from :math:`Bernouli(proportion)`.
- **Train (`train_data_values`)**: Trains many models on random Bernoulli-selected subsets; logs OOB/inclusion patterns and losses.
- **Eval (`evaluate_data_values`)**: Returns the final per-point data values from stored statistics.

## ClassWiseShapley

- **Module:** `dataval/csshap/csshap.py`
- **Method:** Class-wise shapley data valuation implementation
- **Train (`train_data_values`)**: Uses sampler to trains model to find marginal contribs and data values.
- **Eval (`evaluate_data_values`)**: Returns data values for CS-Shapley

## DVRL

- **Module:** `dataval/dvrl/dvrl.py`
- **Method:** Data valuation using reinforcement learning class, implemented with PyTorch.
- **Train (`train_data_values`)**: Trains a value estimator with reinforcement learning to predict per-point utility (DVRL-style).
- **Eval (`evaluate_data_values`)**: Runs the trained value estimator to output per-point values.

## DVRLShap

- **Module:** `dataval/dvrlshap/dvrlshap.py`
- **Method:** DVRLShap: A hybrid data valuation method combining Data Shapley and DVRL.
- **Train (`train_data_values`)**: Trains a value estimator with reinforcement learning to predict per-point utility (DVRL-style).
- **Eval (`evaluate_data_values`)**: Runs the trained value estimator to output per-point values.

## ForgettingEvents

- **Module:** `dataval/fem/fem.py`
- **Train (`train_data_values`)**: Trains across epochs and counts forgetting events per point (correct→incorrect transitions).
- **Eval (`evaluate_data_values`)**: Returns per-point forgetting-event counts as values.

## GAVA

- **Module:** `dataval/gava/gava.py`

- **Eval (`evaluate_data_values`)**: Returns the cached heuristic values.
